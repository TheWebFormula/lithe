Cue's

A Cue is a wrapper around a value that can notify interested consumers when that value changes

${`import { Component, Cue } from '@thewebformula/lithe';
import htmlTemplate from './page.html';

class PageClass extends Component {
  static title = 'Cue';
  static htmlTemplate = htmlTemplate;

  basicBind = new Cue.State('');

  constructor() {
    super();
  }

  updateValue() {
    // HTML will automatically update
    this.basicBind.set('Updated');
  }
}
customElements.define('page-component-name', PageClass);`}
      

${`// example of using Cue.State, Cue.Compute, and Cue.effect

import { Component, Cue } from '@thewebformula/lithe';
import htmlTemplate from './page.html';

class PageClass extends Component {
  static title = 'Cue: State Compute effect';
  static htmlTemplate = htmlTemplate;

  one = new Cue.State(1);
  // Compute will run when first created
  two = new Cue.Compute(() => {
    return this.one.get() * 2;
  });

  constructor() {
    super();

    // runs when any state or computes contained inside change
    // effect will run when first created
    const dispose = Cue.effect(() => {
      if (this.two.get() > 10) {
        // do some work
      }
    });

    // dispose effect
    dispose();
  }
}
customElements.define('page-component-name', PageClass);`}

Cue compute

Compute provides a way to interact with multiple Cue states to provide a single value

Value (Input x 2): ${page.numberTimesTwo.get()}
${`



Value (Input x 2): \${page.numberTimesTwo.get()}
`}
        

${`import { Component, Cue } from '@thewebformula/lithe';
import html from './page.html';

class PageClass extends Component {
  static title = 'Compute';
  static htmlTemplate = html;

  number = new Cue.State(1);
  numberTimesTwo = new Cue.Compute(() => {
    return this.number.get() * 2;
  });
}
customElements.define('page-component-name', PageClass);`}

Cue effect

Effects allows you to run code based on any changes for Cue states or computes it contains. The difference between effect and compute is that effects do not return values.

${`import { Component, Cue } from '@thewebformula/lithe';
import html from './page.html';

class PageClass extends Component {
  static title = 'Effect';
  static htmlTemplate = html;

  one = new Cue.State(1);
  two = new Cue.State(2);
  disposeEffect;

  constructor() {
    super();

    this.disposeEffect = Cue.effect(() => {
      if (this.one.get() < this.two.get()) {
        // do some work
      }
    });
  }

  disconnectedCallback() {
    super.disconnectedCallback();
    this.disposeEffect();
  }
}
customElements.define('page-component-name', PageClass);`}
