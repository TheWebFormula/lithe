Build

The build system includes everything you need. It handles develoment and production bundling and tooling.

Links

  • Build
  • Script injection: index.html

Features

  • Development server
    • Live reload
    • CSS hot swapping
    • Sourcemaps
    • HTTPS
  • Minification
  • Chunking
  • Compression (Brotli, GZip)
  • File copying
  • Environment variable injection
  • CSP html meta tag (Content-Security-Policy)
  • Extendable (uses esbuild underneath)

Behavior

By default the build will automaticly adjust itself based on NODE_ENV.

  • NODE_ENV = production
    • Minification enabled
    • Dev-server disabled
    • Sourcemaps disabled
  • NODE_ENV = other_value
    • Minification disabled
    • Dev-server enabled (with livereload)
    • Sourcemaps enabled

Basic setup

${`import build from '@thewebformula/lithe/build';

build({
  entryPoint: 'app/app.js', // "app/app.js" is the default
  entryPointCSS: 'app/app.css', // no entry css bundling if not specified
  copy: [
    { from: 'app/sitemap.xml', to: 'dist/' },
    { from: 'app/favicon.ico', to: 'dist/' }
  ]
});`}

All options

${`import build from '@thewebformula/lithe/build';

build({
  // App javascript file : Default 'app/app.js'
  entryPoint: 'app/app.js',

  /** App styles file
   * If you add a path, the file will be bundled and output as a single .css file
   * Default: undefined
   */
  entryPointCSS: 'app/app.css',

  // index.html file : Default '[entryPoint root folder]/index.html'
  indexHTML: 'app/index.html',

  // output folder : Default 'dist/'
  outdir: 'dist/',

  /** Minify code
  * 'true' when 'NODE_ENV=production' otherwise is 'false'
  */
  minify: true,

  /** Create source maps
  * 'false' when 'NODE_ENV=production' otherwise is 'true'
  */
  sourcemap: false,

  // Compress files with Brotli or Gzip
  compression: false,
  compressionConfig: {
    type: 'brd',
    level: 19
  },

  // inject env vars
  define: {
    'process.env.SOME_VAR': process.env.SOME_VAR
  },

  // supports regex's with wildcards (*, **)
  copy: [
    {
      from: 'app/image.jpg',
      to: 'dist/'
    },
    {
      from: 'app/routes/**/(?!page)*.html',
      to: 'dist/routes'
    }
  ],

  /** Dev-server
  * 'false' when 'NODE_ENV=production' otherwise is 'true'
  */
  devServer: {
    enable: true,

    // 'false' when 'NODE_ENV=production' otherwise is 'true'
    livereload: true,

    host: 'localhost',
    port: 3000,
    cacheHeaders: false,

    // SSL options for local https
    keyfile: '/tmp/ssl/dev.local.key',
    certfile: '/tmp/ssl/dev.local.crt',

    cors: {
      origin: 'https://localhost'
    }
  },

  /** Content security policy settings
  * This will inject a meta tag into the index.html file with the specified settings
  * defaults to 'false'
  */
  csp: {
    enable: false,
    requireTrustedTypes: false,
    // There is a built in li-html policy that will auto inject
    trustedTypes: [],
    styleSrc: [self, "https://fonts.googleapis.com"],
    fontSrc: [self, "https://fonts.gstatic.com"]
  },

  /** devWarnings
  * Enable console warning
  * only html sanitization currently
  * defaults to 'false'
  */
  devWarnings: false,

  /** securityLevel
  * Set security level warnings for html
  * Default: 1
  * values: 0,1,2
  */
  securityLevel: 1,

  // callback before bundle
  onStart: () => {},

  // callback after bundle
  onEnd: () => {}
});`}
