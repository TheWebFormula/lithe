Create your first page

We will create the required files to render your first page. This includes; index.html, page.js, app.js, and build.js

app/routes/index/index.js

Create the home page. The routes folder is the default routing folder and index is the root. Routing

${`// app/routes/index/index.js

import { Component, Cue, html } from '@thewebformula/lithe';

class PageComponent extends Component {
  static title = 'Page';  // title element value

  someVar = new Cue.state('Hello world');
  shouldShow = new Cue.state(true);

  toggle() {
    this.shouldShow.set(!this.shouldShow.get());
  }

  template() {
    return html\`
      
Page Content

      
\${this.someVar}


      
      \${html(() => this.shouldShow ? html\`
Showing
\` : '')}
    \`;
  }
}
customElements.define('page-component-name', PageComponent);`}

app/app.js

Create main app file to load routes and other modules.

${` // /app/app.js

import './routes/index/index.js';`}

build.js

This is the build script that handles the bundling and development server. Build

${`// build.js

import build from '@thewebformula/lithe/build';

build({ basedir: 'app/' });`}

Run it!

node build.js
