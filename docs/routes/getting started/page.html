Getting started

Welcome! To get you moving we will start with a basic application that will introduce you to the fundementals. You can see the application running in the playground at the bottom of this page.

Create simple app

We will walk through creating a basic app with a single page

Install Lithe

Create folder structure

Create index.html

We will add the basics needed to render a page

  1. Create index.html and place it in app/
  2. Inject application script
  3. Add main tag for page to render in

Create page component

Using the Component class inside the routing folders will automatically handle the route.

  1. Create index.js and place it in app/routes/index/
  2. Set document title
  3. Add styling
  4. Add a Cue variable for tracking clicks
  5. Add template for rendering
  6. Register custom element

Create app entry point

The entry point is used to load your routes and anyother files needed

  1. Create app.js and place it in app/
  2. This file is loaded using a script tag in index.html

Create build script

The build script handles bundling the app and the development server. Build

  1. Create build.js and place it in the root

Run it!

Playground

This example does not use the build process, you will see the ${''} tag added to support this. Usually the build process would automatically add them.
