Routing

There are 2 methods for setting up routes. By default routes will be based on the folder strucutre and naming conventions. You can also directly set the routes using Route component.

Links

  • Directory routing
  • Component routing
  • Route parameters

Directory routing

Routes are based on the folder names and nesting inside the routes/ folder. The build process will automatically create and add the Route components to index.html for you.

app/routes/index/index.js→/
app/routes/404/index.js→404 page
app/routes/one/index.js→/one
app/routes/two[id]/index.js→/two/:id
app/routes/two[id?]/index.js→
/two/:id? (optional)
app/routes/three/[id]/index.js→/three/:id
app/routes/three/[id?]/index.js→
/three/:id? (optional)
app/routes/four[...rest]/index.js→four/*
app/routes/four[...rest?]/index.js→
four/*? (optional)

The build process will automatically inject the li-route tags into the document body

Component routing

You can set routes directly using the Route component. These can be using with the directory routes.

Route parameters

You can access the route parameters inside your page component.
