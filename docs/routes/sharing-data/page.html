Sharing data

Sharing data across components and pages is simple. You can use Cue's in a seperate module.

Example

Update the components input to see the page value change

Component control
Page value
${page.pageValue}

Shared data module

Lets create a simple module that provides data.

Data module

${`import { Cue } from '@thewebformula/lithe';

export const value = new Cue.State('some value');`}

Component

${`import { Component, html } from '@thewebformula/lithe';
import { value } from './data.js';

class ValueInput extends Component {

  template() {
    return html\`
      

        
         value.set(e.target.value)}>
      

    \`;
  }
}
customElements.define('value-input', ValueInput);`}

Page

${`import { Component, html } from '@thewebformula/lithe';
import { value } from './data.js';
import './component.js';


class SharingDataPage extends Component {
  static title = 'Sharing data';

  template() {
    return html\`
      Component control
      

      Page value
      
\${value}

    \`;
  }
}
customElements.define('sharing-data-page', SharingDataPage);`}
