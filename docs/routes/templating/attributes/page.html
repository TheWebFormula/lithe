${`import { Component, html, Cue } from '@thewebformula/lithe';

class InputWrapper extends Component {
  label;
  name;

  /* Cue's will automatically update the element
     No need to manually render */
  #disabled = new Cue.State(false);
  #value = new Cue.State('');

  /* use extended observer for advanced config
     This is a wrapper for static get observedAttributes() { } */
  static observedAttributesExtended = {
    label: { type: 'string' },
    name: { type: 'string' },
    value: { type: 'string' },
    disabled: { type: 'boolean' }
  };

  /* use extended change callback
     - converts dash casing to camel casing
     - return correct type
     This is a wrapper for attributeChangedCallback() { } */
  attributeChangedCallbackExtended(name, oldValue, newValue) {
    this[name] = newValue
  }

  // use to get / set from signal
  get disabled() { return this.#disabled.get() }
  set disabled(value) { this.#disabled.set(value); }

  get value() { return this.#value.get() }
  set value(value) { this.#value.set(value); }

  #onInput(event) {
    // do work
  }


  constructor() {
    super();
  }

  template() {

Attribute types

Lithe supports a wide range of attribute types

  • String
  • toggle (boolean value, but adds / removes attribute)
  • boolean (boolean value, shows as string attr="true")
  • int
  • number
  • object
  • event
Boolean attributes like disabled will be added or removed based on their value
