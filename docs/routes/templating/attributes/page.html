Attribute types

Lithe supports a wide range of attribute types
  • String
  • toggle (boolean value, but adds / removes attribute)
  • boolean (boolean value, shows as string attr="true")
  • int
  • number
  • object
  • event
Boolean attributes like disabled will be added or removed based on their value

import { Component, html, Signal } from '@thewebformula/lithe';

class AttrTest extends Component {
  str = new Signal('value');
  disable = new Signal(false);
  enable = new Signal(true);
  counter = new Signal(1);
  percent = new Signal(0.1);
  data = new Signal({ one: 'one', two: 2 });


  static get observedAttributesExtended() {
    return {

      data: { type: 'object' }
    };
  }

  attributeChangedCallbackExtended(name, oldValue, newValue) {
    // all variables are signals so we can just use .value
