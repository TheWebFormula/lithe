Template lists

There are multiple options for rendering lists. They can be both static and dynamic.

Basic static list

${['One', 'Two', 'Three'].map(item => html`
Value: ${item}
`)}

Dynamic lists with Cue.Array

${page.itemsCheckList.get().map(item => { return html`
${item.label}
item.checked = !item.checked}> `})}

Dynamic lists with Cue.State

Add value ${html(() => page.items.get().map(item => html`
Value: ${item.value}
`))}
