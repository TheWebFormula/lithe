Templates overview

Templates are built using template literals. Simply use the html tag function and write some html.
${`html\`
Welcome \${page.name}
\``}
Lithe template provide support for everything you would expect of a modern framework

  • Attributes: You can configure attributes with a range of types
  • Event attributes: You can bind component methods or use it natively
  • Expressions: Template literals provide robust expression, the only requirement is to return html
  • Iteration: the html template tag can be used as a function providing the ability to handle iterations
  • Variable binding: Signals provide all you need for realtime updates

Templates and components

You can add template to a component / page in two ways. Template method or impart a file

${`import { Component, html } from '@thewebformula/lithe';


// --- Template method ---

class TemplateListsPage extends Component {
  static title = 'Templating lists';

  name = "Bob the builder";

  template() {
    return html\`
Welcome \${this.name}
\`;
  }
}



// --- File import ---

import htmlTemplate from './page.html';

class TemplateListsPage extends Component {
  static title = 'Templating lists';
  static htmlTemplate = htmlTemplate;

  name = "Bob the builder";
}


customElements.define('template-lists-page', TemplateListsPage);`}
